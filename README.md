## 你买到的是不是真家宽：三层验证，少一层都不算数

商家说住宅 IP，不等于平台认它是住宅 IP。自己验一遍，三步。

**第一步，看 ipinfo.io/json 的三个字段。** 通过这台机器访问，返回的 JSON 里重点看 `org`、`hosting`、`type`：

- `org` 显示 “AS7018 AT&T Services” 或 “AS7922 Comcast Cable” 这类个人宽带 ISP，通常是住宅段；显示 DigitalOcean、AWS、Azure 就是机房。
- `hosting` 为 true 是很强的机房信号，这条比 org 更直接。
- `type` 为 isp 是运营商，为 hosting 是数据中心。

**第二步，用 Scamalytics 看风险分和 is_datacenter 字段。** 分数低、is_datacenter 为 false 是好事。有些 IP 段会被整段标记，这不一定代表单个 IP 有问题，但要心里有数。

**第三步，拿目标平台实测。** 你要跑 TikTok 就发一条，要开 Netflix 就看能不能给美区片库，要用 ChatGPT 就登一次。前两步看的是 IP 的登记属性，这一步看的是平台实际怎么判断你。

有一点必须说清楚：`type` 描述的是“拥有这个 ASN 的组织类型”，不是对每一个 IP 的保证。同一家公司网络里可能同时有家庭宽带和商业线路，单看一个字段得出“百分百住宅”的结论并不可靠。ASN 归属、地理位置是否落在居民区、目标平台能不能正常用，三点合起来才是可信判断。

这也是为什么建议先月付。$25 试一个月，验完三件事再决定要不要续、要不要升档。

## 条款比价格更值得看：四类会实际执行的限制

住宅 IP 类产品的条款比普通 VPS 严得多，下面几条都是页面上明确写出的。

**端口限制。** SixtyNet 住宅产品线不开放 80 和 443，理由是 IP 风控。这意味着默认端口下的建站、部分需要标准 HTTPS 端口的 API 回调都会受影响。想建站的人，这条产品线直接排除。

**访问默认关闭。** 同站标注 AS9929 中国优化 + 住宅 IP 的那组配置（2 核 2G / 40G / 5TB 起），额外写明拒绝所有外部探测与扫描，未配置时访问受限，只有白名单或端口转发的设备能连进去。安全性和稳定性是提升了，但上手第一步不是登录，是先配白名单。

**退款口径不一致。** 上述 9929 + 住宅 IP 的配置写明退款仅限网站余额，不是原路退回现金。住宅四档页面上没有单独标注退款条款，下单前用客服问清楚，别默认“不满意能退”。

**竞品的红线可以参考。** ZoroCloud US-Astra 禁止建站（违者封禁且无退款）、禁止机场及任何形式转售或资源再分发，已有真实清退案例。丽萨主机纽约独享 1Gbps VDS 禁止垃圾邮件、邮件群发、攻击扫描、钓鱼诈骗等易引起 IP 投诉的用途，一经发现或投诉立即停机不退款，且 9–15 天手动交付。住宅 IP 被投诉一次就可能整段报废，商家在这些条款上不会手软。

## 二手过户的 AT&T 家宽 VPS：便宜的部分是凭证风险

VPS 二手过户市场偶尔会出现 AT&T 家宽商品的转让，配置大致是 1 核 / 1GB / 20GB / 200Mbps / 2048GB 流量，标价 ¥180/月，过户后沿用原续费价格。价格和 SixtyNet 的 $25 起步档差不多，但多了一层风险。

平台在商品页写得很直白：过户只变更账号归属，VPS 保留原有系统和数据，**原卖家可能仍掌握 SSH 密钥、系统密码或其他远程访问方式**。接手后第一件事是重装系统，然后更换全部登录凭证，检查有没有残留的密钥和后门账号。省下的那点钱，不值得赌一次被远程登录。

另一件事是卖家的状态描述。页面上“未被墙”“送中不确定”“刚购买、流量用不到 1G”都属于卖家自述，不是平台检测结果。IP 有没有被目标平台标记、能不能过验证，只有你自己按前面三步验过才算数。
